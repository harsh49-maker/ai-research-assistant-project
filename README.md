
# 🤖 AI Research Assistant

An AI-powered research assistant built using Python, Streamlit, SmolAgents, Hugging Face, and web-search capabilities.

The application allows users to enter research questions in natural language. The AI agent researches the query using available tools and generates an informative response through an interactive web interface.

---

## 📌 Project Overview

The AI Research Assistant is designed to make research easier, faster, and more interactive.

Users can enter a research question into the application, and the AI agent processes the query, gathers relevant information using web-search capabilities, and generates an AI-powered response.

This project demonstrates the practical use of Agentic AI, Large Language Models, AI agents, web search, and Streamlit application development.

## 🔄 How It Works

The application follows an agent-based research workflow:

```text
                    User
                      │
                      ▼
            Enter Research Question
                      │
                      ▼
             Streamlit Interface
                      │
                      ▼
              SmolAgents Agent
                      │
                      ▼
                 Web Search
                      │
                      ▼
            Information Processing
                      │
                      ▼
              AI Language Model
                      │
                      ▼
              Generated Answer
                      │
                      ▼
                    User
````

---

## 🧩 System Components

### 1. User Interface

Streamlit is used to create the interactive web interface where users can enter research questions and view the generated responses.

### 2. AI Agent

SmolAgents is used to create an AI agent that can perform research tasks using available tools.

### 3. Web Search

The search tool allows the agent to retrieve relevant information from the web while processing research-oriented questions.

### 4. Language Model

A Large Language Model processes the user's question and the information collected during the research process.

### 5. Response Generation

After processing the available information, the AI-generated response is displayed to the user through the Streamlit interface.
