# 🤖 AI Research Assistant

An AI-powered research assistant built using Python, Streamlit, SmolAgents and Hugging Face.

## ✨ Features

- 🤖 Agentic AI research assistant
- 🔎 Web search
- 🧠 AI-powered responses
- 💬 Natural-language questions
- 🎨 Interactive Streamlit interface
- ⚡ Fast research responses

## 🛠️ Technologies

- Python
- Streamlit
- SmolAgents
- Hugging Face
- DuckDuckGo Search
